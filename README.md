# F1-Figure-outline-build


Project Goal: Creating a Functional RC F1 Car



This project's main goal is to build an actual working, motorized RC Formula 1 car. This CAD model is the first component design I made.



I already have the  mechanical and electronic components needed to make the car run, which is the motor, wheels, axle rod, and battery.



This chassis piece was designed using Onshape to provide the rigid body needed to form the F1 car's shape.



I created the exact mounting points and alignment required to connect the motor, the axle rod (drivetrain), and eventually the battery into a single, cohesive, working vehicle.




So far the basic structural chassis piece is complete and ready for the first prototype print to verify the fit with the existing motor and wheels.
